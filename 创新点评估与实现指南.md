### 创新点1：多任务学习框架 ⭐⭐⭐⭐⭐

**创新性评分：5/5**

#### 核心思想
单一Transformer模型同时完成市场状态识别（择时）和个股收益预测（选股），通过共享底层特征表示实现任务间的相互增强。

#### 创新点详解

**1. 与传统方法的对比**
```
传统方法：
  择时模型（独立） → 仓位决策
  选股模型（独立） → 股票排序
  问题：两个模型独立训练，无法共享信息

本方法：
  共享Transformer Encoder
    ├─ 择时任务头 → 市场状态分类
    └─ 选股任务头 → 个股收益预测
  优势：
    - 共享特征学习，提升数据利用效率
    - 择时信息可指导选股（通过注意力机制）
    - 减少模型参数，降低过拟合风险
```

**2. 技术亮点**

**(a) 动态任务权重**
```python
class AdaptiveTaskWeighting(nn.Module):
    """自适应任务权重：根据训练阶段调整损失权重"""
    
    def __init__(self, n_tasks=2):
        super().__init__()
        # 可学习的任务权重（log空间）
        self.log_vars = nn.Parameter(torch.zeros(n_tasks))
    
    def forward(self, losses):
        """
        Args:
            losses: [regime_loss, ranking_loss]
        Returns:
            weighted_loss
        """
        # 不确定性加权（Kendall et al. 2018）
        precision = torch.exp(-self.log_vars)
        weighted_loss = (
            precision[0] * losses[0] + self.log_vars[0] +
            precision[1] * losses[1] + self.log_vars[1]
        )
        return weighted_loss

# 使用示例
task_weighter = AdaptiveTaskWeighting()
total_loss = task_weighter([regime_loss, ranking_loss])
```

**(b) 跨任务注意力**
```python
class CrossTaskAttentionLayer(nn.Module):
    """跨任务注意力：选股任务attend到择时任务的隐状态"""
    
    def __init__(self, d_model, n_heads=4):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(d_model, n_heads)
        self.norm = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.ReLU(),
            nn.Linear(d_model * 4, d_model)
        )
    
    def forward(self, stock_features, market_features):
        """
        Args:
            stock_features: [batch, n_stocks, d_model]
            market_features: [batch, seq_len, d_model]
        """
        # 跨任务注意力
        attended, attn_weights = self.cross_attn(
            query=stock_features.transpose(0, 1),
            key=market_features.transpose(0, 1),
            value=market_features.transpose(0, 1)
        )
        attended = attended.transpose(0, 1)
        
        # 残差连接
        stock_features = self.norm(stock_features + attended)
        
        # 前馈网络
        stock_features = stock_features + self.ffn(stock_features)
        
        return stock_features, attn_weights
```

### 创新点2：因子动态加权机制 ⭐⭐⭐⭐

**创新性评分：4/5**
**实现难度：3/5**
**学术价值：4/5**

#### 核心思想
因子的有效性随市场状态变化。例如：
- 牛市：动量因子权重↑，估值因子权重↓
- 熊市：质量因子权重↑，成长因子权重↓

通过神经网络自动学习这种动态关系。

#### 实现方案

**方案A：基于市场状态的因子加权**
```python
class MarketAdaptiveFactorWeighting(nn.Module):
    """市场自适应因子加权"""
    
    def __init__(self, n_factors, d_model, n_regimes=3):
        super().__init__()
        # 为每个市场状态学习一组因子权重
        self.regime_factor_weights = nn.Parameter(
            torch.randn(n_regimes, n_factors)
        )
        self.factor_embed = nn.Linear(n_factors, d_model)
    
    def forward(self, factors, regime_probs):
        """
        Args:
            factors: [batch, n_stocks, n_factors]
            regime_probs: [batch, n_regimes] 市场状态概率分布
        """
        # 计算加权的因子权重
        # [batch, n_regimes] @ [n_regimes, n_factors] = [batch, n_factors]
        dynamic_weights = regime_probs @ self.regime_factor_weights
        dynamic_weights = torch.softmax(dynamic_weights, dim=-1)
        
        # 应用权重
        # [batch, 1, n_factors] * [batch, n_stocks, n_factors]
        weighted_factors = factors * dynamic_weights.unsqueeze(1)
        
        # 嵌入
        embedded = self.factor_embed(weighted_factors)
        
        return embedded, dynamic_weights
```

**方案B：连续的因子权重生成器**
```python
class ContinuousFactorWeighting(nn.Module):
    """连续因子权重生成器"""
    
    def __init__(self, n_factors, d_model):
        super().__init__()
        # 市场状态编码器
        self.market_encoder = nn.Sequential(
            nn.Linear(n_factors, 64),
            nn.ReLU(),
            nn.Linear(64, 32)
        )
        
        # 因子权重生成器
        self.weight_generator = nn.Sequential(
            nn.Linear(32, n_factors),
            nn.Softmax(dim=-1)
        )
        
        self.factor_embed = nn.Linear(n_factors, d_model)
    
    def forward(self, factors, market_factors):
        """
        Args:
            factors: [batch, n_stocks, n_factors]
            market_factors: [batch, seq_len, n_market_factors]
        """
        # 编码市场状态
        market_state = market_factors[:, -1, :]  # 取最新时刻
        market_encoding = self.market_encoder(market_state)
        
        # 生成因子权重
        factor_weights = self.weight_generator(market_encoding)
        
        # 应用权重
        weighted_factors = factors * factor_weights.unsqueeze(1)
        embedded = self.factor_embed(weighted_factors)
        
        return embedded, factor_weights
```

### 创新点3：图神经网络增强 ⭐⭐⭐

**创新性评分：5/5**
**实现难度：4/5**

#### 核心思想
股票之间存在关联关系（行业、供应链、股东网络），用图神经网络（GNN）捕捉这些联动效应。

#### 图构建方案

**方案A：行业关系图**
```python
def build_industry_graph(stocks, industry_mapping):
    """构建行业关系图"""
    import networkx as nx
    
    G = nx.Graph()
    
    # 添加节点
    for stock in stocks:
        G.add_node(stock, industry=industry_mapping[stock])
    
    # 添加边：同行业股票相连
    for i, stock1 in enumerate(stocks):
        for stock2 in stocks[i+1:]:
            if industry_mapping[stock1] == industry_mapping[stock2]:
                G.add_edge(stock1, stock2, weight=1.0)
    
    return G
```

**方案B：相关性图**
```python
def build_correlation_graph(returns, threshold=0.3):
    """基于收益率相关性构建图"""
    # 计算相关系数矩阵
    corr_matrix = returns.corr()
    
    # 构建邻接矩阵
    adj_matrix = (corr_matrix.abs() > threshold).astype(float)
    np.fill_diagonal(adj_matrix.values, 0)  # 去除自环
    
    return adj_matrix
```

#### GNN模型实现

```python
import torch.nn.functional as F

class StockGNN(nn.Module):
    """股票图神经网络"""
    
    def __init__(self, n_factors, d_model, n_layers=2):
        super().__init__()
        self.factor_embed = nn.Linear(n_factors, d_model)
        
        # GNN层
        self.gnn_layers = nn.ModuleList([
            GraphConvLayer(d_model, d_model)
            for _ in range(n_layers)
        ])
        
        self.output = nn.Linear(d_model, 1)
    
    def forward(self, node_features, adj_matrix):
        """
        Args:
            node_features: [n_stocks, n_factors]
            adj_matrix: [n_stocks, n_stocks]
        """
        # 嵌入
        x = self.factor_embed(node_features)
        
        # GNN传播
        for gnn_layer in self.gnn_layers:
            x = gnn_layer(x, adj_matrix)
            x = F.relu(x)
        
        # 预测
        scores = self.output(x).squeeze(-1)
        
        return scores


class GraphConvLayer(nn.Module):
    """图卷积层"""
    
    def __init__(self, in_dim, out_dim):
        super().__init__()
        self.linear = nn.Linear(in_dim, out_dim)
    
    def forward(self, x, adj):
        """
        Args:
            x: [n_nodes, in_dim]
            adj: [n_nodes, n_nodes]
        """
        # 归一化邻接矩阵
        deg = adj.sum(dim=1, keepdim=True)
        deg_inv_sqrt = torch.pow(deg, -0.5)
        deg_inv_sqrt[torch.isinf(deg_inv_sqrt)] = 0
        norm_adj = deg_inv_sqrt * adj * deg_inv_sqrt.T
        
        # 图卷积: D^(-1/2) A D^(-1/2) X W
        support = self.linear(x)
        output = torch.matmul(norm_adj, support)
        
        return output
```

```python
class TransformerGNNModel(nn.Module):
    """Transformer + GNN混合模型"""
    
    def __init__(self, config):
        super().__init__()
        # Transformer编码器（时序特征）
        self.transformer = TransformerEncoder(...)
        
        # GNN编码器（关联特征）
        self.gnn = StockGNN(...)
        
        # 融合层
        self.fusion = nn.Linear(d_model * 2, d_model)
        
        # 输出层
        self.output = nn.Linear(d_model, 1)
    
    def forward(self, factors, adj_matrix):
        # Transformer编码（时序）
        temporal_features = self.transformer(factors)
        
        # GNN编码（关联）
        graph_features = self.gnn(factors[:, -1, :], adj_matrix)
        
        # 融合
        combined = torch.cat([temporal_features, graph_features], dim=-1)
        fused = self.fusion(combined)
        
        # 预测
        scores = self.output(fused)
        
        return scores
```

### 创新点4：对比学习预训练 ⭐⭐⭐⭐

**创新性评分：5/5**
**实现难度：4/5**
**学术价值：5/5**

#### 核心思想
借鉴NLP和CV领域的预训练思想，先在无标签数据上进行对比学习预训练，再在有标签数据上微调。

#### 对比学习框架

```python
class ContrastiveLearning(nn.Module):
    """对比学习预训练"""
    
    def __init__(self, encoder, temperature=0.07):
        super().__init__()
        self.encoder = encoder
        self.temperature = temperature
        
        # 投影头
        self.projection = nn.Sequential(
            nn.Linear(d_model, d_model),
            nn.ReLU(),
            nn.Linear(d_model, 128)
        )
    
    def forward(self, x1, x2):
        """
        Args:
            x1, x2: 同一股票的两个不同时间窗口
        """
        # 编码
        z1 = self.projection(self.encoder(x1))
        z2 = self.projection(self.encoder(x2))
        
        # 归一化
        z1 = F.normalize(z1, dim=-1)
        z2 = F.normalize(z2, dim=-1)
        
        return z1, z2
    
    def contrastive_loss(self, z1, z2):
        """NT-Xent损失"""
        batch_size = z1.size(0)
        
        # 拼接
        z = torch.cat([z1, z2], dim=0)  # [2*batch, dim]
        
        # 计算相似度矩阵
        sim_matrix = torch.matmul(z, z.T) / self.temperature
        
        # 构建标签（对角线为正样本）
        labels = torch.arange(batch_size).to(z.device)
        labels = torch.cat([labels + batch_size, labels])
        
        # InfoNCE损失
        loss = F.cross_entropy(sim_matrix, labels)
        
        return loss
```

#### 数据增强策略

```python
def augment_time_series(factors, method='jitter'):
    """时序数据增强"""
    if method == 'jitter':
        # 添加噪声
        noise = torch.randn_like(factors) * 0.1
        return factors + noise
    
    elif method == 'scaling':
        # 缩放
        scale = torch.randn(factors.size(0), 1, 1) * 0.1 + 1
        return factors * scale
    
    elif method == 'window':
        # 时间窗口偏移
        shift = np.random.randint(-5, 5)
        return torch.roll(factors, shift, dims=1)
```

#### 预训练流程

```python
def pretrain(model, unlabeled_data, epochs=100):
    """对比学习预训练"""
    contrastive_model = ContrastiveLearning(model.encoder)
    optimizer = AdamW(contrastive_model.parameters(), lr=1e-4)
    
    for epoch in range(epochs):
        for batch in unlabeled_data:
            # 数据增强
            x1 = augment_time_series(batch, method='jitter')
            x2 = augment_time_series(batch, method='scaling')
            
            # 前向传播
            z1, z2 = contrastive_model(x1, x2)
            loss = contrastive_model.contrastive_loss(z1, z2)
            
            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
    
    return model  # 返回预训练后的模型
```
