## 🚨 重要提醒

### 常见错误（必须避免）
1. ❌ 用T周数据预测T周收益 → ✅ 用T-1周数据预测T周
2. ❌ 只用当前成分股历史数据 → ✅ 包含退市股票
3. ❌ 忽略交易成本 → ✅ 扣除万2.5佣金+0.1%滑点
4. ❌ 在测试集上调参 → ✅ 严格区分训练/验证/测试
5. ❌ 财务数据用报告期对齐 → ✅ 用"报告期+45天"规则
